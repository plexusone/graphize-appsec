## [v0.3.0] - 2026-05-09

### Highlights

- Initial public release with 16 reachability tests
- VEX generation with CycloneDX support for SBOM enrichment
- MkDocs documentation site with PlexusOne theme

### Added

- Reachability test framework with 16 tests across Reachable (7), Exploitable (6), and Damage (3) categories
- VEX generation with CycloneDX JSON support and SBOM enrichment
- Graph query utilities for security analysis using graphfs
- `assess` command for single CVE reachability analysis
- `vex enrich` command to add VEX analysis to existing SBOMs
- `vex generate` command for standalone VEX document creation
- `test list` command to show available reachability tests
- `doctor` command to verify graphize, syft, grype, and trivy installation
- MkDocs documentation with CLI reference, reachability tests, and VEX format guides
- Grafana mock application example for testing reachability analysis
- PlexusOne unified navigation theme

### Documentation

- Getting started guide with installation and quick workflow
- CLI reference documentation for all commands
- Reachability tests reference documenting all 16 tests
- VEX output format reference with CycloneDX examples
- SBOM governance guide with best practices
- Parser landscape reference for multi-language analysis

### Infrastructure

- GitHub Actions workflows for CI, linting, and CodeQL SAST
- Dependabot configuration for Go modules
- golangci-lint configuration
